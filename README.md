# Lab Prático — Ponteiros e Arrays (Unidade 5)

## Objetivo

Praticar a manipulação de vetores, matrizes, strings e ponteiros em C, além de compreender a aritmética de ponteiros e a detecção de acessos fora dos limites de um vetor.

## Exercícios

| Arquivo | Descrição |
|---|---|
| `b1.c` | Maior e média de um vetor |
| `b2.c` | Dobrar um vetor por referência |
| `b3.c` | Inverter uma string sem usar `strlen` |
| `b4.c` | Soma de cada linha de uma matriz 3×3 |
| `b5.c` | Aritmética de ponteiros e endereços de memória |
| `b6.c` | Acesso fora dos limites de um vetor com AddressSanitizer |

## Tecnologias utilizadas

- Linguagem C
- Visual Studio Code
- GCC
- Clang e AddressSanitizer para o exercício 6

## Observação

O acesso fora dos limites em `b6.c` é intencional e foi realizado para demonstrar a detecção de erros de memória.

Os arquivos `.c` contêm os códigos-fonte dos exercícios. Os executáveis gerados durante a compilação não fazem parte da entrega.
